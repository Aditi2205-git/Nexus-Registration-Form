# Nexus Registration Form

A modern and responsive registration form built with HTML, CSS and JavaScript, featuring a futuristic dark interface and client-side form validation.

## Features

- Full name, email and phone number fields
- Password and confirm password fields
- Password visibility toggle
- Profile type selection
- Terms & conditions checkbox
- Client-side form validation
- Password strength indicator
- Password matching validation
- Success message after valid submission
- Responsive design for smaller screens
- Futuristic dark and glassmorphism UI
- Animated grid-style background

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Client-side Form Validation
